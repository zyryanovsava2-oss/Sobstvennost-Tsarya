# Собственность царя для iOS

Нативный SwiftUI-проект. В этой версии заложены:
- русский интерфейс и поиск по русским и оригинальным названиям;
- каталог, фильтры, карточка фильма, избранное;
- встроенный AVPlayer для потоков, на которые есть права;
- отдельный слой каталога и воспроизведения для подключения собственного API.

## Важно
Это исходный проект, не готовый IPA. Для установки на iPhone проект нужно собрать и подписать.
Каталог содержит демонстрационные записи. Фильмы Netflix, Disney+ и других сервисов нельзя воспроизводить в стороннем плеере только на основании подписки пользователя. Для такого воспроизведения нужна официальная интеграция и разрешение правообладателя.
Чтобы добавить реальные источники, подключите сервер каталога и выдавайте `playbackURL` только для потоков, разрешённых вашему приложению.
